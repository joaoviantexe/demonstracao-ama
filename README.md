# AMA — Associação de Mulheres na Amazônia

Site institucional oficial da **AMA (Associação de Mulheres na Amazônia)**, fundada por Mônica Rodrigues de Moura, no bairro do Icuí, Ananindeua/PA.

A plataforma apresenta os projetos sociais, capacitações (como *Ela Empreende*, *Musicalização Infantil*, *Linha Acredita BASA*, *Idiomas*), o catálogo artesanal de biojoias e cosméticos sustentáveis da Amazônia (*AMA Bioessência*), além de canais diretos de contato e atendimento via WhatsApp.

---

## 🌿 Tecnologias Utilizadas

- **HTML5 Semântico:** Acessibilidade, tags estruturais e meta tags Open Graph / SEO.
- **CSS3 Moderno:** Flexbox, CSS Grid, variáveis nativas (`:root`), responsividade fluida e temas integrados.
- **JavaScript Puro (ES6+):** Modal de produtos estilo e-commerce, player customizado de vídeo institucional, carrossel de projetos acessível e animações de revelação por *Intersection Observer*.
- **Sem dependências externas pesadas:** Carregamento ultra-rápido, estático e compatível com Vercel, Netlify e GitHub Pages.

## 🚀 Como Executar Localmente

Como o projeto é construído em web standards puras (sem necessidade de build ou compilação), você pode executá-lo de forma muito simples:

### Opção 1: Com extensão Live Server (VS Code)
Abra a pasta `Site` no VS Code, clique com o botão direito no `index.html` e selecione **"Open with Live Server"**.

### Opção 2: Com Node.js (`npx serve`)
No terminal, dentro da pasta do projeto:
```bash
npx serve .
```
E acesse `http://localhost:3000` no seu navegador.

## 🌐 Deploy na Vercel

O projeto está 100% pronto para deploy na Vercel:

1. Conecte este repositório do GitHub na [Vercel](https://vercel.com).
2. Deixe as configurações padrão (`Framework Preset: Other`, `Root Directory: ./`).
3. Clique em **Deploy**.

Qualquer alteração enviada para a branch `main` gerará um novo deploy automático.
